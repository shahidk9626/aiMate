2. Main product surfaces

Business workspace

Onboarding, team members, connected channels, business profile, FAQs and operating hours.

Unified inbox

All supported conversations, assignment, internal notes, status, human takeover and response history.

CRM pipeline

Contacts, leads, source attribution, qualification fields, stages, owner and follow-up tasks.

AI configuration

Knowledge sources, tone, allowed actions, escalation rules, confidence and handoff conditions.

Automation

Event-triggered workflows, notifications, reminders and permitted follow-up sequences.

Analytics & billing

Channel volumes, response time, qualified leads, conversion metrics, plans and usage limits.

3. Core enquiry lifecycle

Customer message→Verify + deduplicate→Normalize event→Find tenant/contact→AI policy + context→Reply / escalate→Update CRM

The inbound event is persisted before asynchronous processing. Outbound messages are queued, retried safely and recorded. A human agent can take over at any point.

4. Deployment view

Application services

Next.js web app and FastAPI API deployed independently. Worker process runs separately from HTTP request handling.

Managed infrastructure

PostgreSQL database, Redis queue/cache, encrypted secrets, object storage, TLS, backups, logs and monitoring.

MVP principle: start with a modular monolith plus a separate background worker. Avoid microservices until real load and team needs justify them.

6. Trust boundaries and non-functional requirements

Tenant isolation

Every business record is tenant-scoped. Authorization is enforced server-side on every query and mutation.

Webhook safety

Verify provider signatures where supported, validate payloads, deduplicate events and reject replays.

Credential security

Encrypt provider tokens at rest, redact logs, rotate secrets and restrict access.

Reliability

Idempotent jobs, retry with backoff, dead-letter handling and observable delivery states.

AI safety

Ground answers in approved business knowledge; no unsupported promises; human handoff on uncertainty.

Privacy

Retention controls, access audit, export/deletion workflows and minimal personal data collection.
